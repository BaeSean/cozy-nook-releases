# Cozy Nook · With 마나

방을 꾸미고 캐릭터·고양이와 함께 지내는 Windows 데스크톱 컴패니언 게임입니다.

이 저장소는 **배포 파일과 사용 안내**를 위한 공간입니다. 게임 소스 코드는 포함하지 않습니다.

## 다운로드

[Releases에서 배포본 확인](https://github.com/BaeSean/cozy-nook-releases/releases)

첫 공개 테스트를 준비 중입니다. 게시된 릴리스가 없다면 아직 검증 중입니다.

## 실행 방법

Windows 64비트 ZIP 전체를 압축 해제한 뒤 `CozyNook.FourTail.exe`를 실행하세요. .NET 런타임은 포함됩니다. YouTube 플레이어에는 WebView2 Runtime과 인터넷이 필요합니다.

전체·감상·미니·집중 모드를 지원합니다. 트레이 아이콘 우클릭 메뉴에서도 모드를 변경하거나 종료할 수 있습니다.

## 저장 및 업데이트

저장 위치는 `%LOCALAPPDATA%\CozyNook\FourTail`입니다. 새 버전은 별도 폴더에 압축 해제하세요. 저장 폴더를 지우지 마세요. 자동 업데이트는 아직 제공하지 않습니다.
