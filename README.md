# Cozy Nook · With 마나

방을 꾸미고 캐릭터·고양이와 함께 지내는 Windows 데스크톱 컴패니언 게임입니다.

이 공개 저장소는 **배포 파일과 사용 안내 전용**입니다. 소스 코드와 사용자 저장 데이터는 포함하지 않습니다.

## 다운로드

[자동 업데이트 버전 v0.325-beta.1](https://github.com/BaeSean/cozy-nook-releases/releases/tag/v0.325-beta.1)

[Windows 64비트 설치 파일](https://github.com/BaeSean/cozy-nook-releases/releases/download/v0.325-beta.1/BaeSean.CozyNook.WithMana-win-Setup.exe)

Setup을 실행한 뒤 바탕화면 또는 시작 메뉴의 **With 마나**로 실행하세요. .NET 런타임을 포함합니다. YouTube에는 WebView2 Runtime과 인터넷이 필요합니다. 개인 음악은 포함하지 않습니다.

전체·감상·미니·집중 모드를 지원합니다. 트레이 아이콘 우클릭 메뉴에서도 모드를 바꾸거나 종료할 수 있습니다.

## 자동 업데이트와 저장

게임을 시작하면 새 버전을 확인하고 다운로드·적용 후 다시 실행합니다. 공개된 베타 버전도 업데이트 대상입니다. 다운로드를 건너뛰거나 네트워크 오류가 있으면 기존 버전으로 실행합니다.

**0.324 이하 ZIP 사용자는 Setup을 최초 한 번 설치해야 합니다.** 이후에는 새 버전을 직접 내려받지 않아도 됩니다. 예전 ZIP의 실행 파일 대신 설치된 바로가기를 사용하세요.

기존 치즈·구매 아이템·방·설정은 `%LOCALAPPDATA%\CozyNook\FourTail`에 유지됩니다. 이 저장 폴더는 삭제하지 마세요. `.nupkg`와 `releases.win.json`은 자동 업데이트용 파일이며 직접 열 필요가 없습니다.

코드 서명은 아직 적용되지 않았습니다. 초기 테스트 버전이며 다른 PC·DPI·다중 모니터 환경 검증은 계속 필요합니다.
